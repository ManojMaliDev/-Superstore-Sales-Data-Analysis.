
# Superstore Sales Data Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing 9,994 retail sales transactions from a Superstore dataset using MySQL Workbench. The objective was to extract actionable business insights regarding sales performance, customer behavior, and product profitability.

## 🛠️ Advanced SQL Concepts Used
* Common Table Expressions (CTEs)
* Window Functions (`LAG()`, `OVER()`)
* Data Aggregation & Customer Segmentation
* Advanced Data Loading (`LOAD DATA LOCAL INFILE`)

## 📊 Key Business Insights & Findings
* **Overall Performance:** Successfully calculated the exact Total Sales, Total Profit, and overall Profit Margin for the business.
* **Customer Behavior:** Identified the Top 10 High-Value Customers contributing significantly to total sales revenue.
* **Product Health:** Pinpointed the most profitable categories and detected sub-categories that are running into net losses.
* **Sales Trends:** Analyzed Month-on-Month (MoM) sales growth using window functions to reveal seasonal trends and revenue drops.
